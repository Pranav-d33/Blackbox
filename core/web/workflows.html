SDK workflows

Any input. One signed action.

A camera frame, a typed note or a spoken command all end the same way: 0G's sealed model picks one action from the mission profile, the robot checks the signature, and the entry goes into the same hash-chained log. The model can never widen what the robot may do.

Workflow 1 · Vision · Built

The camera asks, 0G decides.

  1. 1Detector flags a mark.On-board, cheap. Only flagged crops go to 0G, about 1.5% of modules in our sim runs.
  2. 2Sealed vision call.Crop + nonce to 0G's model in a TEE. Answer: one label from the profile, e.g. cracked_cell.
  3. 3Unsure? Ask a human.Below the hold threshold the drone waits for the crew (button, text or voice). Timeout means safe-stop.
  4. 4Interlock.Signer allowlisted, signature covers the bytes, nonce echoed, action in the vocabulary.
  5. 5Act and record.Descend or continue. Entry on 0G Storage, anchor on 0G Chain, finding on Arkiv.

Running today for the solar-farm and bridge-deck profiles. Try it in the console.

Workflow 2 · Text · Built

The crew types, 0G maps it to an action.

  1. 1Drone holds.r3m14 is ambiguous. The console asks: descend or continue?
  2. 2Crew types what they see.Glass is shattered from hail, send the repair crew. Or just bird droppings, move on.
  3. 3Sealed text model.0GM-1.0 in a TEE gets the words, the profile's labels and actions, and a nonce derived from this checkpoint and these exact words. Returns cracked_cell · 3 · descend, signed.
  4. 4Interlock on the robot.Same checks as a vision answer. Fly to the highway maps to nothing allowed: refused, logged, still holding. A signed answer to different words, or the earlier vision answer, fails the nonce.
  5. 5Logged, and checkable.The words, their hash, 0G's signed answer and the action go into the same chain. The public verifier re-checks it.

Try it: in the console press Ask the crew; at the next checkpoint the drone holds and a reply box appears in Findings. Code: POST /api/robot/instruct, Adapter.instruct. Real use: a crew walking the rows sees what a 20 cm crop can't (hail damage on the back sheet, a bird nest), and their call becomes evidence instead of a radio message.

Workflow 3 · Voice · Built

Gloves on, screen off.

  1. 1Drone speaks.r3m14 unsure. Descend or continue?
  2. 2Crew chief answers.Drone, go down and look at r3m14.
  3. 3Speech to text.The browser's speech recognition fills the same box and sends it. Next step: whisper-large-v3 on 0G so the transcription is on 0G too.
  4. 4Same as text.Sealed text model maps it to one allowed action; the interlock checks it.
  5. 5Logged as voice.Same entry as text, marked crew voice, with the transcript the robot acted on.

Voice adds one failure mode, mishearing. The interlock bounds it: the worst a misheard command can do is pick the other allowed action, and silence means safe-stop.
